# Estacionamiento de ideas

Regla del [[plan-de-guerra-2026Q4]]: **ninguna empresa ni proyecto nuevo hasta el 12 de
diciembre de 2026.** Toda idea nueva se escribe aquí y se queda aquí. Eso es todo lo que se
hace con ella. Se reabre solo cuando se cumple su trigger, y lo revisa Elvin en la revisión
CEO de los viernes.

```markdown
---

```
