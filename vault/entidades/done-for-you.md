# Done-For-You — Segmento de Empresario / Negocio Físico

**Qué es:** Modelo de venta/implementación de [[autoflow]] dirigido a **empresarios con negocio físico y tráfico establecido**. Elvin se encarga de TODA la implementación, configuración e integración; el cliente solo autoriza y se beneficia.

## Resumen acumulado

Criterio de calificación: negocio tiene punto de venta física, ya recibe leads, tiene tráfico establecido (12+ leads/mes como mínimo). A diferencia de done-with-you (emprendedor/digital que necesita acompañamiento), el empresario done-for-you está listo para delegar y pagar el precio premium.

**Precio típico:** $3,500–$6,000 + mantenimiento $197/$397/mes. La propuesta es "**danos 7 días**" — implementamos SIEMPRE 2 sistemas (generación de citas + atención automática que agenda sola).
